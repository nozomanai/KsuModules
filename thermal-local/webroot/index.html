抬手

松手后 500 毫秒的加速上限。只有一组小核和大核，不随性能、均衡、省电切换。

滑动、启动、动画、解锁和上滑时的临时频率上限。到达某一档的温度后用这一档，直到下一档；低于第一档时，这张表不限制升频。动画是 4227。解锁上滑是 4512：场景 0 是默认，场景 2 是解锁，场景 11 是上滑。性能服务用哪个场景号，就吃哪一档。性能、均衡、省电是三列。关闭覆盖后这张表也撤掉。

多任务 CPU

从应用进入多任务时，性能服务把大核最低频率写成 1996MHz、超大核写成 1689MHz，最高频率写成 2745 和 2649，大约半秒。横屏进入时最低频率是 2400 和 2246。从桌面进入不会触发。关掉后不再写这组 CPU 频率。解锁画面不受影响。

解锁 CPU

解锁时，性能服务把大核最低频率写成 1996MHz、超大核写成 1689MHz，最高频率写成 2745 和 2649，大约半秒。关掉后不再写这组 CPU 频率。GPU 仍会到 734MHz。多任务和抬手不受影响。

动画 CPU

同一份性能表里的 0x1083。解锁动画走这条，应用打开和关闭等窗口动画也共用。它把小核最低写成 1996MHz、大核最低写成 1689MHz，最高写成 2745 和 2649，大约 0.4 秒。关掉后不再写这组 CPU 频率。解锁那条 Type 2 和抬手不受影响。
